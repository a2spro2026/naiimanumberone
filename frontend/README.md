# NA3IMA-numberONE — Frontend

Landing page React premium (FR) pour cuisine & traiteur marocain.

## Stack

React 19 · TypeScript · Vite · TailwindCSS v4 · Framer Motion · Lucide · Swiper · React Router · React Hook Form

## Lancer

```bash
cd frontend
npm install
npm run dev
```

Ouvre [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```
